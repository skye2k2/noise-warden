Noise Floor Gate

  

    The ambient noise floor sets the minimum dBA level worth analyzing. Signals below this
    threshold are treated as background white noise and skip the DSP pipeline entirely
    (spectrum analysis, beat detection, classification filters). This reduces CPU usage on
    the Pi and avoids processing blocks that could never trigger an incident.
  

  

    
    
    
  

  

    Current: {{ cfg.detection.noise_floor_db|default(50.0, true) }} dBA.
    Default is 50 dBA (typical quiet residential ambient). If your environment has a higher
    baseline (near a busy road, HVAC, etc.), raise this accordingly. Set to 0 to disable the gate.
