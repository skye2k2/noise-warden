# Noise Warden v2: Hardened Deployment Edition

Includes:
- FastAPI web UI (5-second refresh)
- incident timeline page (day/week/month selector)
- thresholds vs ordinance page
- config viewer/editor
- per-incident WAV snippet playback
- delete single incident / clear all / export CSV
- song-gap incident merging (default 10s)
- night record-only mode
- optional experimental scaffolds:
  - adaptive subtraction
  - dual-mic differential rejection

This is an engineering aid, not a certified ANSI sound level meter.
